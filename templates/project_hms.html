OVERVIEW

A hospital system built around real workflows.

The Hospital Management System is a web application I'm building to manage different aspects of hospital operations through a centralized platform.

The project focuses on creating a practical system where patients, doctors and hospital staff can interact with the parts of the system relevant to them.

The goal is to build something closer to a real-world application rather than a simple demonstration project.

Type Web Application
Backend Python • Flask
Frontend HTML • CSS • Bootstrap
Status In Development
SYSTEM AREAS

What the system covers.

Patient Management

Patient accounts and information are managed through the system.

Doctor Management

A dedicated system for managing doctors and their associated information.

Appointments

Hospital appointments and related workflows are handled through the platform.

Authentication

Patients can use their mobile number or email to access their account.

Database

Structured data storage for the different parts of the hospital system.

Hospital Workflows

Designed to connect different hospital operations within one platform.

PATIENT ACCESS

Flexible patient login.

Patients can log into the system using either their mobile number or email address.

The mobile number acts as a unique account identifier and remains fixed after registration. Email can remain optional for patients who don't have an email address.
