1. Executive Architecture & Zero-Retention Philosophy

Ephemeral was engineered from first principles around zero data retention and complete user sovereignty. Physical Disk Destruction

When single-view media is opened and replied to, or messages exceed their lifetime, the underlying image files are physically removed from disk storage using os.unlink(), leaving zero disk remnants.

Pillow EXIF / GPS Scrubbing

Every uploaded photograph is passed through an in-memory Pillow image transformation pipeline that completely strips GPS coordinates, camera serial numbers, and device metadata before byte writes.

Search Engine Dating Shield

The 18+ mutual dating platform emits HTTP header X-Robots-Tag: noindex, nofollow across all dating endpoints, shielding user profiles from Google, Bing, and search engine indexers.

FUNCTIONAL ECOSYSTEM

2. Core Platform Modules & Shielded Dating Engine

Ephemeral unifies four specialized communication domains into a seamless, high-performance privacy suite.

Direct Messaging

1. Real-Time 1-on-1 Ephemeral Chat

app/routes/chat.py
  • Bidirectional Real-Time Delivery: Instant WebSocket messaging powered by Flask-SocketIO with room-level broadcast isolation, dynamic presence indicators, and live typing feedback.
  • Configurable Self-Destruct Timers: Users configure conversation lifespans (1 Hour, 24 Hours, or 7 Days). Expired messages are permanently wiped from PostgreSQL and disk.
  • Single-View Media Delivery: Photo messages marked as single-view can only be opened once. When the recipient sends their reply message, the server physically deletes the media file from disk storage.
  • End-to-End Delivery Acknowledgements: Real-time message status transitions (SENT → DELIVERED → READ) without persistent telemetry storage.
18+ Opt-In Dating

2. Shielded Mutual Compatibility Dating

app/routes/dating.py
  • Search-Engine Shielding: All dating views, API endpoints, and media routes strictly transmit X-Robots-Tag: noindex, nofollow, noarchive, guaranteeing complete isolation from public web indexers.
  • Double-Blind Mutual Discovery: Chat capabilities are strictly locked until two users independently like each other's profiles, preventing unsolicited messages and spam.
  • Privacy-Preserving Preference Engine: Granular distance radius filters, mutual interest tags, age preferences, and instant profile hiding.
  • One-Click Instant Unmatch & Block: Instantly wipes the conversation history, unlinks shared single-view assets, and revokes mutual match authorizations.
Community Hub

3. Public Community Chat Rooms

app/routes/rooms.py
  • Themed Discussion Lounges: Real-time public discussion rooms for technology, privacy, open-source development, and creative arts.
  • Live Occupancy Telemetry: Real-time participant counters and dynamic roster updates pushed across WebSockets upon join and leave events.
  • Rolling Buffer Architecture: Public rooms maintain a transient in-memory and rolling 50-message buffer, automatically discarding older messages to prevent archive scraping.
  • Instant Room Moderation: Room moderators can mute disruptive participants, pin community guidelines, and purge messages instantly.
Security & Safety

4. Abuse Triage & Rate-Limiting Guard

app/routes/admin.py
  • User Incident Reporting: End-to-end reporting pipeline allowing users to report suspicious profiles, spam, harassment, or Terms of Service violations.
  • Dynamic Rate Limiting: Enforces token-bucket rate limits on authentication attempts, profile swiping, and message dispatch to mitigate bot abuse.
  • Automated Moderation Triage: Administrative dashboard with flagged account queues, audit action trails, temporary suspensions, and permanent hardware token revocation.
  • Zero-Knowledge Reporting Proofs: Captures only minimal necessary context for moderation verification without archiving unrelated historical chats.

1. Reply-Triggered Unlink

Single-view media is automatically purged the moment the recipient acknowledges or replies to the conversation, ensuring temporary visibility without persistence.

2. Atomic Filesystem Unlink

Calls os.unlink() within a resilient exception handler, preventing orphaned disk fragments and logging verified deletions.

3. Database Metadata Scrub

Simultaneously zeroes out database references, attachment URLs, and file hashes so no lingering metadata remains in PostgreSQL.

⚙️ 02

Engine 2: Pillow Image EXIF & Geolocation Stripping Pipeline

Memory-buffered image re-encoding eliminating GPS coordinates and device fingerprints
app/storage.py:strip_exif
1. Byte-Level In-Memory Scrubbing

Incoming image byte streams are parsed through Pillow (PIL), stripped of all EXIF headers, IPTC tags, and GPS coordinates before writing to disk.

2. Device Fingerprint Eradication

Eliminates device serial numbers, lens models, shutter counts, timestamps, and camera software profiles that could deanonymize users.

3. Format Normalization & Optimization

Re-encodes images to clean WebP/JPEG formats with optimized compression, reducing bandwidth and preventing hidden payload attacks.

  • Presence Heartbeats: Heartbeat-driven online/offline detection without continuous polling overhead.
  • Instant Delivery Push: Pushes new messages directly to active socket connections in sub-50ms latency.

  • 18+ Age Verification Gate: Strict birthday validation ensuring only verified adults access the mutual dating system.
  • Mutual Blind Matching: Unidirectional likes remain strictly confidential until mutual reciprocity occurs.
  • Distance Radius Filtering: Proximity matching without revealing exact GPS coordinates or street addresses.
⚙️ 05

Engine 5: Janitor Cron Daemon & Auto-Purge

  • Automated Expired Cleanup: Runs flask cleanup-expired every 15 minutes, scanning for messages older than configured retention limits.
  • Orphan File Detection: Detects and unlinks any unreferenced media files left in temporary disk storage.
  • Zero Database Bloat: Prevents PostgreSQL database expansion by purging expired message rows and indexes.

Engine 6: Secure Authentication & Hardened Headers

  • CSRF Token Validation: Enforces CSRF tokens across all form submissions and JSON API endpoints.
  • HTTP Security Headers: Comprehensive Content-Security-Policy, X-Content-Type-Options: nosniff, and X-Frame-Options: DENY.
